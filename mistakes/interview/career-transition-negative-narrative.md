# 职业转向叙事中过度强调被动与遗憾

## 1. 错误表现

1. 回答“为什么从计算机视觉转 Java”时，使用“被迫转岗、理由搪塞、很可惜、比较无奈”等表述。
2. 花较长时间解释校招 HC 和组织安排，使四年 Java 后端积累听起来像被动停留，而不是已经形成的真实能力。
3. 没有及时收束到当前选择：为什么现在是 Java 平台后端与 AI Agent 工程的结合，而不是重新竞争纯视觉算法岗。

## 2. 根因

1. 把真实经历完整还原等同于适合面试的职业叙事，没有区分事实诚实与情绪细节。
2. 对早期岗位调整仍保留遗憾，回答时容易进入对前公司决策的评价。
3. 没有准备“过去怎么发生、后来积累了什么、现在主动选择什么”的三段式入口。

## 3. 正确理解

推荐表达：

> 我的研究生方向是计算机视觉，校招时原本应聘算法岗位，后来因为岗位和组织安排进入 Java 业务团队。入职后我没有把它只当成过渡，而是持续做了四年生产后端，逐步承担交易流水与核销业务，积累了数据库、任务可靠性、跨系统状态和排障能力。现在大模型应用进入工程落地阶段，我发现 Agent 平台既需要模型与检索知识，也需要稳定后端，因此我主动把两段经历结合起来，定位为 Java 平台后端加 AI 应用工程，而不是回到纯模型训练岗位。

这个版本不回避岗位调整，但重点是已经形成的能力和当前主动选择。

## 4. 复盘触发条件

1. 被问专业与工作方向为什么不同。
2. 被问为什么离职、为什么转 AI 或未来职业规划。
3. 回答中出现“被骗、被迫、搪塞、后悔、无奈、如果当时”等词。
4. 解释历史超过一分钟，却还没有说到当前岗位匹配。
